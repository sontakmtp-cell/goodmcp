## 3. Dữ liệu nguồn và index

[source-audit.json](evidence/G0/source-audit.json): supplied metadata có 80.204
rows, chỉ preview, không full text. Chỉ đọc NPY header trong NPZ (không nạp
pickle): các member giải nén khoảng 539 MiB. Không xem kích thước array là peak RAM.

Corpus thực tế có **343 TXT, 334 HTML, 39 PDF**. Builder gốc lấy TXT/HTML ở root,
672 file có text → **83.736 chunks × 50.000 features**, 50.005.587 nonzero entries.
Giữ đúng `char_wb`, ngram (1,3), max_features 50.000, min_df 2, max_df 0,85,
sublinear_tf và strip_accents gốc. Chỉ đổi output path ra scratch, capture chính
chunk_text gốc để viết sidecar; không thay thuật toán/chunking/rounding.

`chunks_full.jsonl` kiểm lại đủ **83.736 rows** với metadata, preview và char_count.
39 PDF giữ nguyên, chưa OCR/index trực tiếp; không nói đã tìm hết nội dung PDF.

Các lệch nguồn cần giữ và chuyển tiếp:

- MANIFEST cũ có 695 entries, **1 PDF thiếu**:
  `vn_hightech_incentive_andersen_chinese.pdf`; **535 file size mismatch**.
  Chưa kết luận nguyên nhân; không tải bù/sửa source, không dùng MD5 cũ làm trust root.
- ID chunk gốc dựa stem nên TXT/HTML trùng: 83.736 rows nhưng 49.488 legacy ID
  duy nhất, 34.248 nhóm trùng. Cặp `(source_file,id)` có đủ 83.736 giá trị duy nhất;
  sidecar G0 phải tra bằng cặp đó. G4 mint handle riêng theo contract.
  [chunk-identity.json](evidence/G0/chunk-identity.json).
- Rebuilt index khác supplied index (83.736 so với 80.204 rows); không tuyên bố
  parity với pickle cũ chưa được tin cậy. Search baseline là hàm Python gốc trên
  artifact mới do pipeline local vừa dựng.
- Search gốc cắt top_indices trước giới hạn 3 kết quả/file nên có thể trả ít hơn
  top_k; chưa tối ưu/sửa để nâng điểm. Retrieval recall@5 bộ 30 câu thuộc G4.

## 5. PoC MCP v2 + Authlib qua HTTP

[wire-auth.json](evidence/G0/wire-auth.json): **32 checks passed**. Uvicorn chạy
process riêng, bind 127.0.0.1:8765 trong container network none; httpx/httpx2 gửi
TCP thật, không dùng ASGI TestClient hay Client(server) trong memory.

Luồng: GET login lấy CSRF → POST password owner ngẫu nhiên → authorize với public
client đã đăng ký, state và S256 PKCE → đổi code lấy token resource-bound →
SDK Client pin **2026-07-28** gọi g0_cit → **2.400.000.000 VND** từ hàm gốc với
revenue 50 tỷ/cost 38 tỷ và rate mặc định 20%. Wire có typed schema/output,
modern metadata + mirrored headers, resultType=complete, server/discover;
không initialize, không Mcp-Session-Id.

Các kiểm tra âm: thiếu token 401; token hết hạn/sai resource/workspace 401;
thiếu scope 403; chưa login 401; login CSRF/password sai; redirect lạ; thiếu PKCE;
verifier sai; code replay; resource/redirect sai lúc exchange; input âm;
header mismatch -32020 và version không hỗ trợ -32022; Host/Origin lạ.
Fixtures token được seed trong process thử, không có route test backdoor public.

SDK chỉ cung cấp resource server/verifier; **đã viết ASGI adapter** cho Authlib
core: async buffer form/query giữ duplicates → OAuth2Payload/Request → grant
hooks → response Starlette. Host app enter SDK session manager lifespan khi mount.
Đối chiếu [SDK authorization](https://py.sdk.modelcontextprotocol.io/run/authorization/),
[ASGI mount](https://py.sdk.modelcontextprotocol.io/run/asgi/),
[Authlib reference](https://docs.authlib.org/en/latest/oauth2/authorization-server/flask/api.html).

PoC chỉ một owner/workspace/client pre-approved, store memory; login/token biến
mất khi process dừng. Chưa có DB atomic code consumption, refresh rotation/revoke,
consent UI/rate limit production, TLS/proxy hay host cloud. Chặn fixture workspace
khác **không chứng minh DB/file isolation**; G1 phải chạy hai tenant thật trong DB.
Evidence bỏ Authorization/cookie/password/code/access-token; chỉ lưu traffic MCP.
