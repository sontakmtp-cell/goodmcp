# G3 — importer / registry / storage

Ngày 30/10/2026, Asia/Saigon. Trạng thái **passed (local)**. G2 host cloud gate vẫn blocked.

G3 nhập/kiểm nguồn và cung cấp catalog. Dùng G1 tenant/RLS/ArtifactStore và
G2 OAuth/MCP; không viết lại hoặc thực thi công cụ Python, không deploy cloud.

## 1. Phần bàn giao

| Phần phụ trách | Tệp / hành vi |
|---|---|
| Importer | `plugin_scan.py`, `import_worker.py`, worker loop: ZIP data-only, queue/lease bền vững, retry hữu hạn, preview trước khi enable |
| Registry | `registry.py`: package/version bất biến, installation revision, disable, resources, role bodies, lịch sử/project pins và export |
| Storage | Dùng G1 put/get/stream; thêm seekable verified handle để đọc ZIP không extract; bảo vệ artifact đang được upload tham chiếu |
| DB | Migration `0003_g3`: hai bảng upload/parts với FORCE RLS + composite FK, narrow claim function; trigger giữ source rows immutable |
| API/MCP | `registry_api.py`, main: REST chunk/status/install/export và sáu tool đọc catalog; middleware ASGI giới hạn request |
| OAuth | Thêm `hub:write` vào supported scopes, fresh consent; scope và role owner/admin đều bắt buộc để quản lý plugin |
| Client/test | `pack-g3-samples.py`, CLI import/resume, pytest registry, wire G3, verify G3 từ git archive và image tag riêng |

Giữ nguyên schema/migrations G1/G2 đã phát hành. Runtime/worker chỉ có runtime
secret, không Docker socket, shell executor, pip install hoặc outbound source fetch.
Function claim không cho client chỉ định user/workspace/command; chỉ nhận việc đã
xếp trong DB cho owner/admin còn active. Bản mới chỉ có thể thay installation bằng
revision đúng; scan/publication rollback không chạm bản đang phục vụ.

## 4. Stack local và cách dùng

Hợp đồng và hướng dẫn API: [G3-registry.md](../contracts/G3-registry.md).
CLI: `python scripts/pack-g3-samples.py`, sau đó chạy trong environment G2:
`python scripts/connect-local.py --import-zip ".local/g3-samples/OPC Team.zip" --enable`.
CLI mở browser xin scope hub:read/hub:write; giữ token trong memory và revoke cuối
lượt. Tiếp tục upload bằng `--resume-upload UUID`; cập nhật installation dùng
`--expected-revision N`. Không ghi password/token vào lệnh hoặc file report.

Đã upgrade stack `goodmcp-local` qua `python scripts/local.py up`, giữ owner và
workspace G1 `cfa8baa7-f581-406b-9ceb-a67e71088b46`. **Ba mẫu đã enable revision 1**.
Đã chạy CLI import cho cả ba: HTTP form surrogate cho browser, callback TCP thật
127.0.0.1:8766, official SDK đọc workspace rồi revoke grant. Không lưu/in token.
[local-cli.json](evidence/G3/local-cli.json). Đây là CLI/HTTP evidence, chưa phải
visual review UI hoặc native host agent integration.

CLI mặc định chỉ preview; `--enable` mới chọn version. Dùng revision trả về khi
cập nhật. Readonly connection G2 cũ tiếp tục đọc catalog, không tự được cấp ghi.

## 5. Giới hạn và bàn giao G4

Giữ toàn bộ lịch sử version và immutable blobs trong G3; chưa tự thu gọn về ba
bản chưa ghim hoặc GC blob orphan. Cần backup/pin/retention accounting trước khi
xóa vật lý. Admission quotas cố định được ghi trong contract; chưa có UI đổi
quota theo workspace. Một importer tuần tự, chưa benchmark tải nhiều người.

Cgroup peak bao gồm file cache và khác RSS process; các số đo cuối được tách trong
[memory.json](evidence/G3/memory.json). Peak RSS API **127,43 MiB**, importer
**58,15 MiB**. Cgroup peak API **515,38 MiB** (counter transient so với cap 512),
worker **256 MiB**; có file-cache reclaim tại ngưỡng memory.max, cả hai `oom=0`,
`oom_kill=0`. Không dùng số này để cam kết VPS 8 GB:
G4 phải đo toàn Compose cùng runner/search. Job/plugin executor vẫn thuộc G4.
Tổng thời gian các lệnh harness **224,89 giây**; lượt Finance–Tax gồm upload,
scan/publish, export/hash và kiểm resource mất **74,90 giây**. Đây là kiểm nghiệm
local, không phải benchmark tải nhiều người hoặc tốc độ tool Python.

Đã sửa hai vấn đề trong harness: code OAuth TTL 120s phải tạo **sau** lượt import
lớn để không hết hạn trước recreate; image tag verify phải riêng để local build
không thay image giữa chừng. API dùng pure ASGI cho request metadata/body limit,
tránh giữ nhiều bản đệm khi truyền chunk lớn; stream file không materialize ZIP.

G4 dùng [G3-registry.md](../contracts/G3-registry.md), source UUID/hash và G1
ArtifactStore trong tenant transaction. Chỉ pipeline reviewed mới tạo trusted
index/ToolBinding. **Chưa sửa công thức Python, chưa chuyển TF-IDF sang JS/FTS,
chưa viết/chạy adapter tài chính hoặc engine.**

G2 host cloud gate vẫn **blocked_by_host** do chưa có endpoint HTTPS public được
giao phép thử. G3 local không thay kết quả đó; không deploy/tunnel/DNS/R2 hoặc
tuyên bố hỗ trợ thực tế ChatGPT/Claude/Gemini/Grok.
