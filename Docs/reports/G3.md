# G3 — importer / registry / storage

Ngày 30/10/2026, Asia/Saigon. Trạng thái **in_progress**; chờ lượt verify checkout sạch.

G3 chỉ nhập/kiểm nguồn và cung cấp catalog. Dùng G1 tenant/RLS/ArtifactStore và
G2 OAuth/MCP; không viết lại hoặc thực thi công cụ Python, không deploy cloud.

Hợp đồng và hướng dẫn API: [G3-registry.md](../contracts/G3-registry.md).
CLI: `python scripts/pack-g3-samples.py`, sau đó chạy trong environment G2:
`python scripts/connect-local.py --import-zip ".local/g3-samples/OPC Team.zip" --enable`.
CLI mở browser xin scope hub:read/hub:write; giữ token trong memory và revoke cuối
lượt. Tiếp tục upload bằng `--resume-upload UUID`; cập nhật installation dùng
`--expected-revision N`. Không ghi password/token vào lệnh hoặc file report.

Nguồn được cung cấp dạng thư mục, không có ZIP nhà phát hành. ZIP bàn giao là
snapshot local giữ nguyên tất cả byte file; hash file so với inventory G0. Hai HTML
Finance–Tax có private-key block nhúng từ trang nguồn: giữ trong ZIP private nhưng
quarantine khỏi active resources. Không in giá trị key; không thử dùng credential.

Lệnh nghiệm thu: `./scripts/verify.ps1 -Stage G3` (POSIX: `./scripts/verify.sh G3`).
Chứng cứ sẽ cập nhật sau verify. G2 host cloud còn blocked; local G3 không đóng gate đó.
