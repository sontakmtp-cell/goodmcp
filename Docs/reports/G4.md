## 2. Tài liệu: agent tự chọn từ khóa và đọc nguồn

`hub_list_documents`, `hub_search`, `hub_read_document` đều readonly, chỉ cần
`hub:read`. Không có score/semantic rerank. Keywords literal case-insensitive,
all/any, tối đa 5 chuỗi × 100 ký tự; list/search có cursor, đọc text tối đa 16.384
ký tự/page và next_offset. Agent có thể tìm bằng từ/cụm từ khác rồi đọc tiếp;
không có agent/model phía Hub tự viết câu trả lời.

Plain text và casefold lưu ở PostgreSQL, tìm bằng `strpos` có parameter, **không
FTS/trigram/vector index**. Metadata luôn gắn source resource/version/workspace.
`source_sha256` là hash file gốc; HTML text là bản tách chữ, bỏ script/style/nav,
không render JavaScript. `hub_read_resource` G3 vẫn đọc byte source khi cần.

## 3. Python nguyên bản và job

Chín operations: CIT estimate/schedule, payroll, FCT withholding/gross-up, tariff,
location, compliance calendar, ODI. Module gốc được kiểm SHA trước import và data
được bake trong image immutable. Image calculator **không chứa corpus/index/pickle**;
NumPy/SciPy/scikit-learn không được cài, xác minh trực tiếp từ image:
[runtime-versions.json](evidence/G4/runtime-versions.json).

Giữ rounding và giá trị gốc, gồm hành vi `location_sim cit_override=0` bị nguồn
bỏ qua và trả warning. Province sai không bị âm thầm loại. Refs giữ nguyên stdout
và JSON dữ liệu gốc. Kết quả gắn version/tree/adapter/image/release digest; ngày
nguồn unknown khi chưa biết. Khớp chương trình gốc không phải kiểm toán pháp lý
hoặc xác minh mức thuế hiện hành.

Invocation trả **202/job ngay**, cần `tools:run` và owner/admin/member; không dùng
hub:write thay quyền thực thi. Project output thêm projects:write và pin đúng bản.
Queue tối đa 20/workspace (429 + Retry-After), tối đa hai calculator đang chạy.
Mỗi container 1 CPU/256 MiB/30s, rootfs readonly, non-root, no network, cap_drop ALL,
no-new-privileges, pids 64, job/tmp riêng trên tmpfs. Không secret/DB/socket/host
mount trong calculator. Client không chọn image, command, module, mount hoặc env.

Dispatcher riêng có Docker socket + runtime DB secret; không HTTP endpoint. API
và import worker không có socket. Operator mới được duyệt release/binding, runtime
role không được INSERT/UPDATE/DELETE chúng. Docker socket là quyền đặc biệt trên
host, không coi control plane này là sandbox cho code thù địch công khai.

Job có input và terminal state immutable, lease 30s/heartbeat 5s, tối đa 3 attempts
cho lỗi hạ tầng; fencing chặn worker cũ publish. Cancel running chỉ terminal sau
khi container dừng. Timeout failed, nonzero exit failed; không trả success khi
chưa có artifact/checksum bền vững. Project/version pin và source cũ không bị thay
khi chọn installation khác. Không GC/orphan/retention tự động trong G4.
