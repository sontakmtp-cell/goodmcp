## 2. Hai điểm chặn đã xử lý

### 2.1. Khôi phục đúng môi trường Python được duyệt

Release đang dùng tham chiếu image
`sha256:1f5a9fead877756bb149b10165d6d338dfb4e71922ef73ccc53ad16e843ddeff`,
nhưng Docker không còn tra được image này. Các lớp thực thi và bản ghi BuildKit gốc
vẫn còn. Đã khôi phục OCI index/config/layers/attestation theo đúng từng SHA-256,
kiểm tra 18 blob và nạp lại **chính image cũ**.

- Không đổi `runtime_releases`, tool binding, phiên bản nguồn, project pin hoặc công thức.
- `.local/g4/active/release.json` vẫn khớp từng byte với release gốc đã duyệt.
- Release digest giữ nguyên
  `9613a98c728057a19bdfbd9e2189afc61eb3a4683cbec2a01363879d18d8a9b9`.
- CLI phục hồi: `scripts/restore-local-runtime.py`. Chỉ operator chạy local,
  không có HTTP route hoặc quyền mới cho plugin/client.
- Archive phục hồi được giữ local tại `.local/g4/recovery/approved-1f5a9fea.oci.tar`;
  hash archive được ghi trong biên bản. Đây là artifact Docker phục hồi môi trường,
  không phải triển khai tính năng backup dữ liệu của G8.

Kiểm thử React đã chọn binding thật, điền doanh thu mẫu 1.000/chi phí 600/thuế suất
20, gửi job thật, đọc kết quả Python **80 VND** và xác nhận provenance trùng image,
release và `original_python=true`. Đây là dữ liệu thử tích hợp; không phải tư vấn
hay chứng thực nội dung thuế.

### 2.2. Mỗi yêu cầu HTTP mới phải kiểm tra quyền lại

Đã xác định lỗi trong `apps/api/mcp_auth.py`: credential lưu trong ContextVar có thể
được thừa hưởng vào yêu cầu HTTP mới. Kiểm tra ngoài cùng từng dùng lại credential
này trước khi hỏi DB, khiến một số yêu cầu sau revoke vẫn được chấp nhận.

Chứng cứ trước sửa: revoke trả 200, REST vẫn 200 với đúng token vừa thu hồi, trong
khi verifier mới truy vấn DB xác nhận token không còn hợp lệ. Test tái hiện context
thừa hưởng cũng nhận 200 và không truy vấn DB.

Bản sửa xóa cache thừa hưởng trước lần xác thực ở ranh giới yêu cầu mới. Kiểm tra
MCP bên trong chỉ được dùng lại token vừa xác minh cho chính yêu cầu đó. Không đổi
endpoint, schema, scope, cookie hay kiến trúc OAuth G2.

Sau sửa:

- Credential đã thu hồi bị REST và MCP từ chối với **401** ngay trong chuỗi kiểm thử.
- Credential còn hoạt động vẫn dùng được; inner MCP check không truy vấn DB dư.
- React gọi revoke thật, chỉ bỏ phiên sau probe 401, và xóa nội dung riêng khỏi UI.
- 45 test auth/database permission/runtime bounds đạt; 26 kiểm tra HTTP/MCP đạt
  ở hai phiên độc lập, không dựa vào token hết hạn để làm test xanh.

API/auth/worker/dispatcher local đã được tạo lại bằng image ứng dụng chứa bản sửa,
không xóa volume/database. Không có migration hay thay đổi hợp đồng G1–G5.

## 4. Phân biệt các lớp kiểm thử

**UI tests mặc định:** private catalog, keyboard, clipboard success/error,
loading/empty/network/401/403/404/409/413/422/429/5xx, role, versions/conflict,
HTML độc hại chỉ là text, schema→binding→invocation, job result/cancel, ZIP
resume/hash/mismatch/retry/stop, callback state/issuer/timeout/deny, token storage
và xóa dữ liệu riêng khi 401. Revoke không chấp nhận HTTP 200 đơn lẻ.

**Live React test mới:** render component sản phẩm trong jsdom, dùng G2 OAuth,
API, binding và Python container thật; xác nhận kết quả và thu hồi. Không mock API
hoặc dữ liệu. Chỉ bỏ canvas trang trí do jsdom không có canvas/layout engine.
Kết quả này không được gọi là screenshot hoặc kiểm thử trình duyệt thật.

**Browser lượt trước:** đã kiểm public/private, OAuth callback qua harness local,
ZIP/file chooser/preview/enable/export/disable, Escape/focus return, form gửi job,
revoke→public; Portal ở 320×740, 390×844, 768×1024, 1448×1086 và Admin mobile/desktop
không tràn ngang toàn trang. Menu mobile cuộn riêng. Console lượt kiểm tra cuối không lỗi.

**Giới hạn browser của lượt hoàn thành:** `AGENTS.md` yêu cầu GPT-6.1 Terra medium
điều khiển trình duyệt. Đã gọi đúng agent; agent kiểm được trang public và hướng dẫn
Claude, sau đó chạm hạn mức sử dụng. Không đổi model hoặc tự điều khiển browser
trái quy định. Chưa chụp lại màn hình Python thành công trong browser ở lượt này;
luồng chức năng đó đã qua live React DOM + API + container thật và HTTP/MCP độc lập.
Giao diện sản phẩm không bị sửa trong lượt đóng hai lỗi.

Axe DOM không có violation trong tập rule đã chạy; color-contrast/region loại khỏi
jsdom vì không có layout thật. Cảnh báo getContext của jsdom và cache pytest không
ghi được trong container read-only không làm test thất bại. Không chứng nhận WCAG,
không thử screen reader, OS reduced-motion, Android/iOS thật hoặc upload stress 1 GiB.
Công cụ đọc clipboard trước đó trả rỗng dù write promise thành công; chưa xác nhận
độc lập clipboard hệ điều hành, nhưng test contract xác nhận đúng chuỗi URL.

## 5. Chưa hỗ trợ theo API/phạm vi đã chốt

- User CRUD, toàn bộ connections/grants, revoke kết nối khác, logs, CPU/RAM/đĩa,
  backup trigger/status, list toàn bộ jobs/uploads và full-project export: chưa có API.
- Không invitation/signup/billing/marketplace, công khai private plugin, approve script
  từ UI, LLM/TF-IDF hoặc chạy game engine.
- Dropdown tạo project lấy 100 plugin đầu, có thông báo nếu còn trang; các danh sách
  plugin/project/version/document chính có phân trang.
- Không refresh token tự động, đổi password/TOTP, production routing/DNS/TLS,
  R2 backup hoặc nghiệm thu ChatGPT/Claude/Gemini/Grok cloud.

Đây là giới hạn được thiết kế và công bố trong G6-UI, không phải hai lỗi runtime/revoke
còn treo. Hai lỗi đó đã được đóng bằng kết quả thật ở mục 1–2.

## 6. Chạy và kiểm tra lại

Tại `apps/web`: `npm ci`, `npm run dev`. Mở `http://127.0.0.1:4173/` hoặc `/admin`.
Backend local phải đang chạy ở 18080; URL connector public vẫn là placeholder có nhãn.

```powershell
# Trong apps/web: kiểm tra thông thường, không yêu cầu dữ liệu local
npm test
npm run build

# Tùy chọn: React + backend/Python thật, dùng owner local hiện có
$env:GOODMCP_LIVE = '1'
npm test -- src/test/live.test.tsx
Remove-Item Env:GOODMCP_LIVE

# Trong repo: HTTP và MCP thật, output giữ exit code chính xác
.venv\Scripts\python.exe tests/wire_g6.py
```

Live test đọc credential owner local trong RAM và thu hồi grant khi xong; không
in/lưu credential. HTTP harness tạo dữ liệu synthetic có nhãn và tắt installation
thử trong finally. Browser fixture `g6-browser-acceptance` cũng đã tắt lại. Không
xóa dữ liệu cũ vì chưa có delete API; không đổi nguồn/pin của ba plugin thật.
