## 2. Hành vi đã triển khai

Login xác minh owner đã bootstrap bằng password file local. Password mới Argon2id;
owner G1 scrypt được nâng cấp khi login thành công. Cookie opaque có HttpOnly,
SameSite=Lax, Secure khi cấu hình HTTPS; HTTP loopback được bật riêng cho local.
Login thành công đổi SID; form login/consent/logout kiểm CSRF gắn session. Throttle
đăng nhập lưu DB, chặn brute-force xuyên restart. Không mở signup/invitation user.

Authorize hiện client/scope/workspace và yêu cầu xác nhận rõ. Chỉ membership còn
hiệu lực được chọn; viewer không cấp tools:run/projects:write. DCR chỉ đăng ký
**ứng dụng kết nối**, không tạo user/workspace hoặc tự cấp dữ liệu. Chỉ hỗ trợ
public OAuth client dùng PKCE S256, exact redirect, grant code/refresh.

Access token 5 phút, refresh 7 ngày, code 120 giây, browser session 30 phút. Grant
gắn user/workspace/client/scope/issuer/resource. Code/refresh/session/CSRF/access
được lưu hash; không có plaintext token trong DB. Code và refresh chỉ tiêu thụ
một lần, có row lock và transaction; replay thu hồi family gồm token con vừa cấp.
Refresh chỉ giữ/giảm scope; scope thêm cần consent mới. Revoke token của client
thu hồi cả family. Logout xóa browser session; grant cần revoke riêng.

CIMD chỉ fetch HTTPS/public DNS trên 443, pin IP đã kiểm và TLS SNI/certificate
đúng hostname; không resolve lại khi connect, không theo redirect/proxy env.
Chặn private/link-local/reserved/multicast/mapped private IP; 64 KiB, hạn đọc,
JSON/client_id binding. Chỉ fetch mới sau login hợp lệ hoặc với credential còn
hiệu lực gắn client tại token endpoint. DCR có quota/rate limit, tối đa 500 clients.
CIMD HTTPS fetch/TLS được kiểm bằng unit/mocked network; **chưa live-test một CIMD
document của host cloud** hoặc tuyên bố tương thích mọi metadata/auth method.

API/worker vẫn chỉ có runtime_password. Service auth chỉ có auth_password; không
owner/superuser/BYPASSRLS. API lookup token hash qua SECURITY DEFINER function có
input/SQL cố định, rồi dùng membership/RLS của G1. Runtime không được tạo/edit token
hoặc đọc bảng browser sessions/codes/client registry. Không mount Docker socket.

MCP dùng official SDK **2.3.0**, strict modern **2026-07-28**. Chỉ tool
`hub_get_workspace` readonly, trả workspace_id/name/role. `workspace_id` phải trùng
grant; X-Workspace-ID chỉ là lựa chọn phải kiểm, X-User-ID không làm identity.
`/api/v1/me/workspaces` đọc workspace được grant cho phép. Route nghiệp vụ khác
vẫn chưa triển khai; không mở scope/runtime ghi dữ liệu để làm test dễ qua.

## 5. Lỗi đã xử lý và gate còn lại

Đã sửa regression test G1 để gửi Host public đúng khi gọi API từ network test;
Host sai giờ bị chặn 421 trước auth. Test không được bỏ Host allowlist để lấy 401.
Đã chuẩn hóa lock order grant → credential để kiểm replay đồng thời. Phát hiện
Compose không tự dọn volume thuộc profile test khi profile đó không bật ở lệnh
down; launcher hiện bật test/ops profiles lúc cleanup và kiểm volume còn lại.
Các volume debug của lượt lỗi cũng đã được dọn đúng project của nhiệm vụ.

**Host cloud: blocked_by_host**, [host-check.json](evidence/G2/host-check.json).
Chưa có endpoint HTTPS public được phép triển khai cho Hub G2. ChatGPT/Claude/
Gemini/Grok đều chưa được thử live trong lượt này; không kết luận unsupported hoặc
đã hỗ trợ bốn host. Không tự mở tunnel/đổi DNS/cấu hình dịch vụ có sẵn để tạo pass.
Gate này cần endpoint HTTPS thử có quyền đọc và một host/tài khoản được chọn ở
lượt được giao tiếp; G7 tiếp tục báo cáo từng host thật.

Trước production còn TOTP/recovery code, TLS/proxy nhiều hostname, cấu hình IP
tin cậy cho rate limit sau proxy và đo lại RAM toàn Compose. G2 thêm auth cap
512 MiB; budget trần G0 tăng tương ứng, chưa phải số đo hoặc cam kết VPS 8 GB.
Support hiện tại là public client/PKCE; các auth method/metadata khác cần test
host thực tế, không tự fallback legacy. Không công bố backup/restore production
đạt từ phép recreate local.

G3 local có thể dùng token/Principal/TenantContext và contract G0 để tích hợp
registry/storage khi được giao; gate host cloud vẫn giữ mở. G4 mới triển khai
runtime nghiệp vụ, không chuyển công thức Python sang JS/FTS trong G2.
