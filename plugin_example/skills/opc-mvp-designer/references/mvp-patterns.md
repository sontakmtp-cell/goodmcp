# MVP patterns
| Pattern | Tests | Minimum execution kit | Limitation |
| --- | --- | --- | --- |
| Manual service | Willingness to pay and delivery feasibility | Offer, booking questions, delivery checklist | Founder time may not scale |
| Content/paid session | Demand for a specific result and purchase | Sample, invitation draft, registration/payment plan | Likes do not validate purchase |
| Landing page / preorder | Demand for a clear offer | Honest page copy, form, price, fulfillment/refund terms | Separate interest, commitment and actual payment |
| One-function prototype | Task completion and repeated usefulness | Core flow, task instructions, event log | Usage alone does not prove paid demand |

Choose the cheapest reversible test that can disprove the riskiest assumption.
Include minimum content and steps to run in 05; route acquisition path to 06.
Do not require asset-systematization stage 07 before launch. Build only what the
test needs and respect user scope.
