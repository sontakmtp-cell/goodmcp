# Stop and review rules
Agree limits before the next cycle. Separate hard constraints from investigation
signals. Do not invent universal conversion-rate thresholds.

| Trigger | Action |
| --- | --- |
| Confirmed money/time/capacity limit reached | Pause affected experiment; user chooses stop, shrink or explicitly extend |
| Sample/window completed below failure threshold | Compare original hypothesis; propose one change or stop |
| Repeated tests show no useful leads | Check targeting, exposure, tracking and sample before concluding no demand |
| Negative contribution or delivery hours exceed assumptions | Recalculate price/scope/capacity before scaling |
| Heavy channel/customer dependence | Quantify share and consequence; propose bounded contingency/diversification test |
| Missing or contradictory tracking | Mark inconclusive; repair measurement before claiming validation |

Specify trigger, source, owner, review date and authorized action.
Use founder-confirmed constraints and actual test design. Positive signals do not
authorize increased spending or extended limits.
