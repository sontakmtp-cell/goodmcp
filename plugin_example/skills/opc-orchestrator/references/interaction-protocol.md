# Interaction protocol
Follow the shared runtime contract; this adds pacing guidance only.
- Teaching: explain the current concept and purpose briefly before asking.
- Guided: explain key concepts only, then advance using existing answers.
- Direct: minimize explanation and proceed from known context and authorization.
- Infer mode when the user's request is clear; do not impose a questionnaire.
- On long discussions, summarize confirmed facts, unresolved questions and next
  action. Offer a draft checkpoint. No fixed turn limit or automatic completion.
- Present meaningful options with evidence and tradeoffs. Recommend when useful;
  the user may select, combine, revise or replace them.
- Clear requests to continue, skip, revise or draft first execution materials
  supply intent for that work; do not add redundant confirmation.
- Save confirmed decisions using the file contract; never call drafts confirmed.
