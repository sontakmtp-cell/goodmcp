# Stage routing
| Need | Route | Prerequisite / outcome |
| --- | --- | --- |
| Inventory founder resources | 01 → opc-resource-audit | Eight categories |
| Select a niche | 02 → opc-niche-positioning | Resources; three rings and six-dimension comparison |
| Clarify why customers buy | 03 → opc-value-proposition | Selected segment and positioning |
| Define business model | 04 → opc-business-model-design | Value proposition; canvas and risky assumptions |
| Design/prepare first experiment | 05 → opc-mvp-designer | Prioritized hypothesis; measurable test and execution materials |
| Reach, capture and convert | 06 → opc-conversion-loop | MVP; conversion path and first action |
| Execute and collect evidence | execution → lead with 05/06 as needed | First post/message/form/checklist without requiring 07 |
| Systematize repeated outputs | 07 → opc-asset-ops | Actual reusable operating outputs |
| Diagnose operations | 08 → opc-dashboard-review | Operating experience/data, even sparse |

Default: 01 → 02 → 03 → 04 → 05 → 06 → execution. Stage 05 is MVP design.
07/08 are conditional tools, not mandatory linear steps. Return to execution or
an explicitly selected earlier stage. Use confirmed conversation context in place
of absent prerequisite files. Record authorized skips and uncertainty.
First execution content belongs to 05/06; turning repeated outputs into a reusable
system belongs to 07. Route by purpose, not by whether the output is a post.
On rollback preserve history, identify affected conclusions and revalidate only
affected outputs. Do not restart the entire workflow by default.
